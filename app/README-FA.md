# Mazorya App — نسخه اولیه PWA

## استقرار

1. ساب‌دامین `app.mazoryagroup.com` را روی هاست بساز و SSL/HTTPS را فعال کن.
2. **محتوای داخل این پوشه** را در Document Root ساب‌دامین بارگذاری کن؛ پوشه را به‌صورت یک سطح اضافه آپلود نکن.
3. باید آدرس‌های `https://app.mazoryagroup.com/`, `/app.js`, `/manifest.webmanifest`, `/sw.js` و `/icons/icon-192.png` باز شوند.
4. در مرورگر Chrome اندروید گزینه Install app / Add to Home screen را انتخاب کن. نصب به HTTPS و شرایط مرورگر وابسته است.

## استفاده

- دفعه اول نام (دلخواه) و دامنه مشتری را ثبت کن؛ مثال `clientdomain.com` به `https://api.clientdomain.com/admin/login` تبدیل می‌شود.
- اگر آدرس متفاوت است، آدرس کامل HTTPS را وارد کن؛ مثلاً `https://panel.example.com/login` یا `https://apii.mazoryagroup.ir/admin/login`.
- لینک‌ها در LocalStorage همان مرورگر/اپ ذخیره می‌شوند. پاک‌کردن داده سایت، فهرست را پاک می‌کند؛ هنوز دیتابیس مرکزی یا همگام‌سازی بین گوشی‌ها نداریم.
- دکمه **Open My Dashboard** پنل را در مرورگر/زبانه جدا باز می‌کند. رمز و لاگین در دامنه مشتری انجام می‌شود.
- ذخیره آدرس تأییدیه مالکیت یا سلامت دامنه نیست. برای انتشار عمومی به مشتریان واقعی، پنل‌ها بهتر است از فهرست تأییدشده مرکزی ارائه شوند تا لینک‌های جعلی نمایش داده نشوند.
- خود لانچر بعد از یک بار بازدید می‌تواند آفلاین نمایش داده شود، اما پنل خارجی برای کارکرد اینترنت نیاز دارد.

## نسخه اندروید APK

بعد از انتشار PWA با HTTPS می‌توان با Trusted Web Activity / Bubblewrap یک پروژه اندروید ساخت. برای APK واقعی به Android SDK/build environment و امضای APK نیاز است. برای نمایش بدون نوار آدرس باید Digital Asset Links (`/.well-known/assetlinks.json`) با اثرانگشت گواهی امضای واقعی هم تنظیم شود. این بسته APK نیست.

## بروزرسانی

با هر انتشار مهم شناسه کش در `sw.js` را از `mazorya-launcher-v1` به نسخه بعدی تغییر بده.
